# С вечера

Лендинг тестирует заявленную готовность купить набор из 6 порций за 990 ₽ с доставкой по Москве. Посетитель выбирает готовность платить и формат доставки. Контакты и платежи не собираются.

## Локальный запуск

На Node.js 24 или новее запустите `npm start`. Страница открывается на `http://127.0.0.1:4173/`, сводка находится на `http://127.0.0.1:4173/results`. Данные остаются в файле `demand.sqlite`. Продакшен-сборка выполняется командой `npm run build`. На Sites Worker использует привязку D1 `DB` и SQL-схему из файла `schema.sql`.

Ссылка с `?utm_source=telegram` или `?utm_source=vk` учитывается как отдельный источник. Источник закрепляется при первом визите, а ответы подсчитываются по одному на браузер. Сводка содержит только агрегаты. Для проверки после запуска можно использовать отдельный браузер и пометку `?utm_source=qa`.
